One sentence a house cat says in its own defence, five seconds after knocking a glass off the table. No apology, no confession, just the cat's case: the glass took its sunspot, stared all morning and paid no rent, so it got evicted.

`main.py` writes that sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
